# Kunstmuseum

フォルダ単位で画像を閲覧し、タグ（カテゴリ／ジャンルなど）で整理して、タグと画像の関係を「知識グラフ」として可視化するデスクトップ画像ビューアです（Electron 製、Windows 向け）。

## 起動方法

```powershell
npm install      # 初回のみ（Electron と cytoscape を取得）
npm start        # アプリを起動
```

開発用コマンド:

| コマンド | 内容 |
|---|---|
| `npm test` | 単体テスト（store / fsops / レイアウトモデル / スライドショーの再生順）。`node --test test/` でも実行できます |
| `npm run dist` | Windows インストーラのみビルド（`dist\`）。通常は `release.ps1` を使用 |
| `npm run icon` | アプリアイコン `build/icon.ico` を再生成 |
| `npm run smoke` | スモークテスト。一時フォルダにテスト画像を作り、別の userData でアプリを 2 回起動（2 回目はレイアウト復元の確認）・自動操作して終了コード 0/1 を返します（実際のデータには触れません）。`KM_SMOKE_BULK=5000` で大量画像のテスト |

## インストール

```powershell
pwsh ./release.ps1 -Install
```

- 単体テストとスモークテストを実行してから Windows インストーラ（NSIS）をビルドし、サイレントインストールします
  （インストーラだけ作るときは `pwsh ./release.ps1`、成果物は `distKunstmuseum-Setup-<version>.exe`）
- インストール先: `D:Program Filesmy_original_appkunstmuseum`（`-InstallDir` で変更可）
- ショートカット: デスクトップとスタートメニューに「Kunstmuseum」が作成されます
- アプリが起動中の場合はインストールを中断します。アプリを閉じてから実行してください
- データ（タグ・登録フォルダ・レイアウト・設定）は `%APPDATA%Kunstmuseumlibrary.json` にあり、
  `npm start` の開発版と共通です。インストール・更新・アンインストールのいずれでも削除されません。画像ファイルにも一切書き込みません
- アンインストール: Windows の［設定］＞［アプリ］＞［インストールされているアプリ］で「Kunstmuseum」を選んで［アンインストール］
- 未署名のため、Windows Defender が `Kunstmuseum.exe` を誤検知して隔離することがあります。その場合は管理者権限の PowerShell で
  `Add-MpPreference -ExclusionPath "D:Program Filesmy_original_appkunstmuseum"` を実行してから再インストールしてください

## 機能

### エディターグループとタブ（VSCode 風）
- メイン領域は 1〜4 個の「エディターグループ」を横に並べた構成です。グループごとにタブバーがあり、アクティブなグループはタブバー上端のアクセント線で示されます。グループ間の境界はドラッグで幅を変更できます
- タブの種類
  - **ギャラリー**: 複数開けます。フォルダ・サブフォルダを含む・検索・並び順・タグ絞り込み・サムネイルサイズ・選択・スクロール位置をタブごとに保持します
  - **知識グラフ**: 1 つだけ。**Alt+Q** でアクティブなグループの右隣に表示できます（フォーカスはそのまま）
  - **Preview**: 1 つだけ。ギャラリー・サイドバー・グラフで最後に選択した画像を常に表示します（タブ名は斜体の「Preview: ファイル名」）。**Alt+P** でアクティブなグループの右隣に表示できます（フォーカスはそのまま）
  - **画像タブ**: 1 つの画像を固定表示します。同じ画像が既に開いていればそのタブに移動します
- 画像を開く（ギャラリーのダブルクリック／Enter、サイドバーやグラフのダブルクリック）と、Preview があるグループ（開いた場所と別のグループの場合）に画像タブが開きます
- タブのドラッグ: タブバー上で並べ替え、他のグループのタブバーへ移動。グループの内容部分にドロップすると左右半分と中央のガイドが表示され、左右なら新しいグループを作成（最大 4 つ）、中央ならそのグループへ移動します
- タブの右クリック: 閉じる／他のタブを閉じる／右に分割／左に分割／左のグループへ移動／右のグループへ移動。中クリックで閉じます
- 分割: ギャラリーは同じ状態で複製、知識グラフと Preview は移動、画像タブは別グループに同じ画像を開きます
- 空になったグループは自動的に閉じます。タブが 1 つもないときは「ギャラリー／知識グラフ／Preview」を開くボタンを表示します。各タブバーの「＋」からも開けます
- 初回起動時は「ギャラリー｜Preview」の 2 グループ構成です。レイアウト（グループ・幅・タブ・各ギャラリーの状態）は保存され、次回起動時に復元されます（存在しなくなった画像のタブは除外）

### サイドバー（フォルダとファイル）
- 「フォルダを追加」ボタン、またはエクスプローラーからサイドバーへのドロップでフォルダを登録
- ツリーでフォルダを展開すると、サブフォルダの後に対応画像ファイルを拡張子付きで表示します（種類ごとのバッジ付き、自然順）。500 件を超えるフォルダは「さらに表示（残り n 件）」で続きを表示
- 上部の「ファイルを表示」でファイルの表示／非表示を切り替え（設定は保存されます）
- フォルダのクリック: アクティブなギャラリータブ（なければ最近使ったギャラリー、それもなければ新しいタブ）で表示。Ctrl+クリックまたは右クリック「新しいギャラリータブで開く」で新しいタブに表示
- ファイルのクリック（Ctrl／Shift で複数選択）で Preview とインスペクタを更新し、そのフォルダを表示中のギャラリーでも同じ画像を選択します。ダブルクリックで画像タブを開きます
- ファイルの右クリック: 名前の変更／新しいタブで開く／エクスプローラーで表示／パスをコピー
- フォルダの右クリック: 新しいギャラリータブで開く／名前の変更／エクスプローラーで表示／一覧から外す（ルートのみ。ディスク上のファイルは一切変更しません）
- 登録フォルダごとに変更を監視し、ギャラリーと展開中のツリーを自動更新します（選択とスクロール位置は維持）

### ギャラリー
- ツールバー: ファイル名検索、並び順（名前〔自然順〕／更新日時／サイズ、昇順・降順）、「サブフォルダを含む」、サムネイルサイズ、更新
- タグで絞り込み（複数指定は AND 条件）
- 「全フォルダ（タグ付き画像）」で、登録フォルダ内のタグ付き画像をまとめて表示

### ビューア（Preview／画像タブ）
- 初期表示は画面に収まるサイズ（100% を超えて拡大しません）。Ctrl+ホイールでカーソル位置を中心に拡大・縮小、ドラッグで移動、ズーム率を右下に表示
- ←／→ は画像を開いた元のギャラリーの並び順で前後に移動します（Preview ではそのギャラリーの選択も移動、画像タブではタブの表示画像が切り替わります）

### スクリーン表示（スライドショー）
- **Ctrl+Alt+Shift+O** でどこからでも「スクリーン表示」ダイアログを開きます（文字入力中・他のダイアログ表示中を除く）
- 対象: **フォルダ**（登録フォルダとそのサブフォルダから選択、「サブフォルダを含む」）または **カテゴリ**（種類ごとに分類されたタグから 1 つ選択。全フォルダのタグ付き画像が対象）
- 切り替え秒数（既定 5 秒、1〜3600 秒）、順番（名前順／ランダム）、ループ（既定 ON）。前回の設定を記憶します
- 「スクリーン 開始」（Enter）で全画面表示を開始。黒背景に画面いっぱいに表示し（小さい画像も拡大）、次の画像を先読みしてクロスフェードで切り替えます。GIF／APNG／WebP はアニメーション、SVG はくっきり表示されます
- 表示中はディスプレイのスリープを抑止し、2 秒操作がないとカーソルを隠します。マウスを動かすとファイル名・番号・間隔・状態を表示します
- 読み込めない画像は自動的にスキップします。ループ OFF の場合は最後の画像で止まり「終了」と表示します
- Esc で終了すると元のウィンドウ状態に戻り、最後に表示した画像が選択されます（Preview に表示）

### タグ
- 右側のインスペクタで、選択中の画像のプレビュー・寸法・サイズ・更新日時・パスを表示
- タグの追加（入力補完。既存タグの選択、または種類を選んで新規作成）と削除（×）
- 複数選択時は全画像に共通するタグを表示し、一部の画像だけに付いたタグは「一部」と表示（クリックで全てに追加）
- 「タグ管理」: 種類（名前・色）の追加・変更・削除、タグの名前変更・種類変更・統合・削除
  - タグの削除はメタデータのみで、画像ファイルは変更されません

### 知識グラフ
- タグ（種類ごとの色、使用数に応じた大きさ）とタグ付き画像（サムネイル）をノードとして表示
- 範囲（現在のフォルダ＝最近使ったギャラリーのフォルダ／全フォルダ）、表示する種類、モード（画像+タグ／タグ共起のみ）を切り替え
- ノードにマウスを乗せる・クリックすると隣接ノードを強調。画像ノードのクリックで Preview とインスペクタに表示、ダブルクリックで画像タブを開く
- タグノードをダブルクリックすると、最近使ったギャラリー（なければ新しいギャラリー）をそのタグで絞り込みます
- ノード検索、レイアウト再計算、全体表示

### 名前の変更と移動
- ファイル名の変更（ギャラリーやツリーで F2、または右クリック。ビューアでは F2 でダイアログ）。拡張子を除いた部分が選択された状態で編集できます
- 使用できない文字・Windows の予約名・非対応の拡張子はエラーになります。拡張子を変える場合は確認が表示されます。大文字・小文字だけの変更にも対応
- サムネイルやツリーのファイルを、サイドバーのフォルダまたは別のギャラリー（フォルダ表示中のもの）へドラッグ＆ドロップすると移動（複数可）
- **同名のファイルがある場合は上書きせずにスキップ**し、件数を通知します。ファイルを削除する機能はありません
- 名前の変更・移動をしても、タグ・画像タブ・Preview・すべてのギャラリーが新しい場所に追従します

### 設定
- サイドバー下端の「⚙ 設定」または **Ctrl+,** で開きます（Esc／閉じる で閉じる）
- **ホットキー**: 全体のショートカットの一覧と変更。［変更］を押してから新しいキーを押します（Esc でキャンセル）
  - Ctrl または Alt を含む組み合わせが必要です（F1〜F12 は単独可）。Esc・Enter・Space・矢印・Tab（Ctrl なし）や、システムが使うキー（Alt+F4、F10、F12 など）は割り当てられません
  - 他の操作と重複した場合は「入れ替える」か選べます。［既定に戻す］／［すべて既定に戻す］で元に戻せます
  - 変更はすぐに反映され、変更した分だけ保存されます。場面ごとの固定キー（ビューアの ←/→・1・0、ツリーやギャラリーの矢印・Enter など）とマウス操作も一覧できます
- **操作説明**: アプリの使い方の要約（キーは現在の割り当てで表示）
- **一般**: サイドバーにファイルを表示、新しいギャラリーの既定サムネイルサイズ、スクリーン表示の既定秒数、データの保存場所（［フォルダを開く］）、バージョン

## 対応拡張子

`.jpg` `.jpeg` `.png` `.svg` `.gif` `.webp` `.avif` `.bmp` `.ico` `.apng`（大文字・小文字は区別しません）

アニメーション GIF / APNG / WebP はアニメーション表示されます。SVG は拡大してもくっきり表示されます。

## データ保存場所

- 登録フォルダ・タグ・設定（タブとグループのレイアウト、並び順、サムネイルサイズ、パネル幅、ウィンドウ位置など）は
  `%APPDATA%\Kunstmuseum\library.json` に保存されます
  （Electron の `app.getPath('userData')`。一時ファイルに書き込んでから置き換えるため、書き込み中に終了しても壊れにくくなっています）
- 画像ファイル自体にはタグ情報を書き込みません
- 起動時、存在しなくなった画像のタグ情報は自動で整理されます（接続されていないドライブ上の画像は保持されます）
- `library.json` が壊れていた場合は `library.json.corrupt-<日時>` としてコピーを残し、新しく作成します
